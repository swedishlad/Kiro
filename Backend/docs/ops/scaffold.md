# Scaffold (W0b: the orchestrator, 15 min, before any agent starts)

`scaffold/` is a minimal project that was **built and tested on Oct 23 2026** from a fresh copy:
- `npm ci` → 292 packages, `npm audit` → **0 vulnerabilities**
- `next build` → static `out/`
- vitest + fast-check → 1 test passed
- Playwright → 2/2 passed (375 px light, 1280 px dark), with screenshots and no console errors

## Steps
```bash
# from the repo root (the kit already copied in)
cp -r scaffold/. .                 # package.json, lockfile, configs, app/, public/, tests/
npm ci                             # exact versions from package-lock.json
npx playwright install chromium    # once per laptop (downloads the browser)
npx next build && npm test && npm run e2e
git add -A && git commit -m "orchestrator: scaffold (W0b; exempt from G-OWN)"
```
All three commands must pass before W1 starts. If `npm ci` fails, see the notes below.

## Build command by phase
- **Before release's W1 merge:** `npx next build` (data isn't wired yet; `build:data` is a placeholder).
- **After release merges `copy-and-validate-data.ts`:** `npm run build` (= `build:data` + `next build`). The orchestrator updates `package.json` scripts at that merge, at release's request.

## Notes from testing (Oct 23)
- **Re-tested Oct 23 evening on TC's Mac (Node 25.8.0, npm 11.16.0):** `npm ci` 6 s, `next build` passes, vitest 1/1. npm 11 prints `allow-scripts` warnings for esbuild, fsevents and msgpackr-extract (install scripts not run); build and tests passed anyway, so ignore them. Playwright was not re-run.
- **Next.js 16.0.0–16.4.0 have critical advisories** (GHSA-2464-fhr4-w9xw and GHSA-673q-mjm6-r5xr, both RCE; GHSA-p3m5-59mp-jv5r, DoS). The scaffold pins **16.4.2**, which `npm audit` reports clean. Never downgrade.
- **vitest 5.0.3 and 5.0.4 fail to install with npm 10.9.4** (`Cannot read properties of null (reading 'edgesOut')`, reproduced in fresh folders). **5.0.5 installs and runs.** It's pinned despite being newer than our 14-day rule.
- `npm ci` prints deprecation warnings for `prebuild-install` and `geographiclib`, which mapshaper pulls in. They're build-time only and never shipped to the browser.
- In sandboxes whose bundled browser differs from Playwright's expected build, set `PW_CHROMIUM=/path/to/chrome`. The config passes it as `executablePath`. Not needed on a normal laptop after `npx playwright install chromium`.
